📱 Android Votre appareil

Télécharger l’application (APK)
Comment installer le fichier ?
  1. Téléchargez le fichier. Si Chrome indique que ce type de fichier peut être dangereux, choisissez « Télécharger quand même ».
  2. Ouvrez-le. Si Android demande l’autorisation, appuyez sur Paramètres, activez « Autoriser depuis cette source », puis revenez en arrière.
  3. Appuyez sur Installer, puis sur Ouvrir.

Sans fichier : dans Chrome, menu ⋮, puis « Installer l’application ».

💻 Windows Votre appareil

Télécharger pour Windows
Comment installer ?
  1. Téléchargez le fichier (pour Windows 10 ou 11, 64 bits), puis ouvrez-le.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
  3. Suivez l’installation, puis ouvrez StockFacture Pro depuis le Bureau.

Sans fichier : dans Chrome ou Edge, cliquez sur l’icône d’installation à droite de la barre d’adresse.

🍎 iPhone Votre appareil

  3. Choisissez « Sur l’écran d’accueil », puis Ajouter.
